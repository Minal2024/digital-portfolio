````{tab-set}
```{tab-item} Things I learned
- I learned that the spacing and format of specific files are important when making your Jupyter Book. For example, if the spacings are incorrect in the `_toc.yml` file, the book will run into errors.
I learned how to hide cell input by clicking on the input code, going to Advanced Tools, and adding a tag to hide the input in the cell metadata section. This can make the Jupyter Notebook appear cleaner and more organized. 
- I learned that we do not need to create the `_config.yml` and `_toc.yml` files; they are automatically created when the book is created.
````
